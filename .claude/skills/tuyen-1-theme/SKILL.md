# Tuyen_1 Theme

A muted, earthy color theme: sage-green body text, olive-lime headings, and a bold
magenta-pink accent reserved for emphasis — supported by a wide flexible palette of
dusty rose, clay, and mauve tones.

Set as the **default theme for all artifacts** starting 2026-08-10. Apply it
automatically when creating artifacts in this project; do not ask the user to
pick a theme unless they request something different for a specific piece.

## Color Palette

### Core roles (fixed meaning — do not repurpose)

| Role | Hex | Usage |
|---|---|---|
| Body text | `#7d8471` | All standard paragraph/label text |
| Headings | `#6B8C0C` | Titles, section headers, headline elements |
| Wichtiges (Important/Accent) | `#E2185E` | Sparingly: key callouts, alerts, primary CTAs, critical data points |

### Supporting palette (beliebig — flexible: backgrounds, charts, cards, borders, secondary accents)

`#E37F76` `#d17484` `#ab80b3` `#a4ac86` `#d4a5a5` `#b87d6d` `#ae6965` `#cc8471`
`#a490c2` `#8d5aae` `#ddafa0` `#d7b4b4` `#d7c780` `#ddbaae` `#b86b6b` `#86c3ff` `#6390b0`

## Usage Guidance

- **Body text** (`#7d8471`) for all standard paragraph and label text.
- **Headings** (`#6B8C0C`) for all titles, section headers, and headline elements.
- **Wichtiges** (`#E2185E`) sparingly — only the most important elements: key
  callouts, alerts, primary CTAs, or data points that must stand out. Never use
  it as a general accent or decorative color.
- Draw from the **supporting palette** freely for backgrounds, chart series,
  cards, tags, borders, and secondary accents. These 17 colors are
  interchangeable — mix and match to suit the artifact.
- Keep contrast readable: pair light supporting tones with the darker core
  colors (headings/wichtiges) for text, and avoid stacking two similarly light
  supporting tones against each other for text.
- For light/dark-mode artifacts, treat these as the light-mode palette; darken
  backgrounds and lift text tones as needed to preserve contrast in dark mode
  rather than inventing unrelated colors.

## Typography

- **Headings**: a bold serif (e.g. Georgia, FreeSerif Bold) works well against
  the olive-lime heading color.
- **Body**: a clean sans-serif (e.g. system-ui, FreeSans) for readability.

## Best Used For

Personal projects, organic/lifestyle content, editorial or journal-style
documents, nature and wellness themes — anywhere a soft, earthy palette with
one bold accent color is wanted.
