Stufe 00 · Ausgangslage

Der Dicarbonylpool

Aus Weg A und Weg B ist ein α-Dicarbonyl entstanden — 3-DG (Dicarbonyl an C1/C2) oder 1-DG (an C2/C3). Beide tragen dieselbe Struktureinheit: zwei Carbonylgruppen direkt nebeneinander.

Warum ausgerechnet zwei Carbonyle?

Das ist die eigentliche Pointe, und sie lässt sich zeichnen: entsteht am C ein Carbanion, kann es nur dann delokalisieren, wenn direkt daneben ein C=O sitzt.

MerksatzEin einzelnes Carbonyl kann Amine binden. Erst zwei nebeneinander können Aminosäuren zerlegen.
Stufe 01 · Pfeile ①–⑦

Kondensation: Aminosäure trifft Dicarbonyl

Dieselbe Choreografie wie schon zweimal zuvor: Hand ran ans C → Doppelbindung hoch → protonieren → Stickstoff drückt Wasser raus. Sieben Pfeile, fünf Zeichnungen.

1.1 — Nucleophiler Angriff ①②

  • 1Das freie Elektronenpaar am Stickstoff greift das elektrophile Ca an → neue N–Ca-σ-Bindung.
  • 2Simultan: das π-Elektronenpaar der Ca=O klappt hoch auf den Sauerstoff → Ca–O⊖.

1.2 — Protonentransfer ③ → Halbaminal

  • 3Das Alkoholat holt sich ein Proton (Lösungsmittel bzw. vom N⊕), das N⊕ gibt seins ab. Netto: neutrales Halbaminal.

1.3 — Protonierung der OH-Gruppe ④

  • 4Das freie Elektronenpaar am Ca-OH-Sauerstoff greift ein Proton → Ca–OH₂⊕, eine gute Abgangsgruppe.

1.4 — Wasseraustritt ⑤⑥ → Iminiumion

  • 5Das freie Elektronenpaar am Stickstoff schiebt in die N–Ca-Bindung → Ca=N⊕.
  • 6Simultan: die Ca–OH₂⊕-Bindung bricht heterolytisch, das Elektronenpaar geht zum Sauerstoff → Wasser tritt aus.

1.5 — Deprotonierung ⑦ → Schiff-Base

  • 7Eine Base nimmt das Proton vom N⊕ → neutrale Schiff-Base (Azomethin).

Stufe 02 · Pfeile ⑧–⑪

Decarboxylierung: der eigentliche Strecker-Schritt

2.1 — Konzertierte CO₂-Abspaltung ⑧⑨⑩

  • 8Das Bindungselektronenpaar der Cα–COO⊖-Bindung schiebt in die Cα–N-Bindung → neue Cα=N.
  • 9Simultan: die π-Elektronen der Ca=N klappen hinunter aufs Ca → Carbanion.
  • 10Simultan: CO₂ tritt aus.

2.2 — Ladungsauffang ⑪ → Enolat

  • 11Das Carbanion am Ca schiebt in die Ca–Cb-Bindung; gleichzeitig klappt das π-Elektronenpaar der Cb=O auf den Sauerstoff → Enolat.

Stufe 03 · Pfeile ⑫–⑯

Hydrolyse: die zwei Produkte trennen sich

Exakt umgekehrt zur Bildung — nur greift diesmal Wasser an, und zwar am Cα, weil dort jetzt die Doppelbindung sitzt.

3.1 — Wasserangriff ⑫⑬

  • 12Das freie Elektronenpaar eines Wasser-Sauerstoffs greift das elektrophile Cα an.
  • 13Simultan: die π-Elektronen der Cα=N klappen auf den Stickstoff. Nach Protonentransfer: Halbaminal.

3.2 — Protonierung des Stickstoffs ⑭

  • 14Der Stickstoff wird protoniert → er wird zur guten Abgangsgruppe.

3.3 — Spaltung ⑮⑯ → die zwei Produkte

  • 15Das freie Elektronenpaar am Cα-OH-Sauerstoff schiebt in Cα → Cα=O bildet sich.
  • 16Simultan: die Cα–N-Bindung bricht, das Elektronenpaar geht zum Stickstoff → Trennung.

Stufe 05 · Endstation

Melanoidine: das Ende der Straße

Die reaktiven Dicarbonyle und Aldehyde reagieren immer weiter mit Aminogruppen — vor allem mit der ε-Aminogruppe des Lysins, weil die frei zugänglich aus der Proteinkette herausragt. Ergebnis: Vernetzung und Polymerisation.

Ernährungsphysiologische PointeLysin wird durch die Bindung biologisch unverfügbar → Verlust einer essenziellen Aminosäure. Das ist der wichtigste Nachteil der Maillard-Reaktion. Nachweis der Hitzeschädigung: Furosin, das bei der Säurehydrolyse aus den Amadori-Produkten des Lysins entsteht — Standardmarker z. B. in Milch.
Kettensatz

Das Rückgrat, einmal am Stück

Ring auf → Amin greift C1 an → Schiff-Base → N-Glykosid → Amadori-Umlagerung → ARP → pH-Gabelung: sauer 1,2-Enolisierung → 3-DG, basisch 2,3-Enolisierung → 1-DG → Dicarbonylpool → Strecker: Kondensation, Decarboxylierung, Hydrolyse → Strecker-Aldehyd + α-Aminoketon → 2× Aminoketon → Dihydropyrazin → Oxidation → Pyrazin → Vernetzung mit Lysin → Melanoidine.
